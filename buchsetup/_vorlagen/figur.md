# Vorlage: Figur

Checkliste, keine Pflichtfelder. In die Figurendatei kommt nur, was schon feststeht oder vorgeschlagen ist; leere Abschnitte werden weggelassen.

```
# Name

Rolle: Hauptfigur / Perspektivträger / Nebenfigur

## Kanon
## Ideen & Vorschläge
## Offene Fragen
```

Themen, die mit der Zeit gefüllt werden:
- Steckbrief: Alter, Herkunft, Äußeres
- Ziel (was sie will), Bedürfnis (was sie wirklich braucht), Angst
- größte Stärke, größte Schwäche
- Beziehung zum Stoff
- Vorgeschichte
- Entwicklung im Buch (Bogen): Pflicht für jede Figur, sobald sie mehr als eine Szene trägt
- Stimme: wie sie denkt und spricht, typische Wörter, Satzlänge, Humor
